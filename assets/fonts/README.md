# Noto Serif KR

Figma의 읽기용 서체를 네트워크 요청 없이 표시하기 위한 로컬 자산이다.

- 원본 프로젝트: https://github.com/google/fonts/tree/main/ofl/notoserifkr
- 배포 자산: https://fontsource.org/fonts/noto-serif-kr
- 글꼴: Noto Serif KR Regular (400), Korean / Latin WOFF2
- 다운로드: 2026-09-14
- 라이선스: SIL Open Font License 1.1. 원문은 `OFL-NotoSerifKR.txt`에 동봉한다.
- 파일의 실제 글리프 데이터는 변경하지 않았다. UI 본문은 기존 Pretendard를 재사용한다.

다운로드 주소:

- https://cdn.jsdelivr.net/fontsource/fonts/noto-serif-kr@latest/korean-400-normal.woff2
- https://cdn.jsdelivr.net/fontsource/fonts/noto-serif-kr@latest/latin-400-normal.woff2

앱은 위 주소를 호출하지 않으며 저장소에 포함된 파일을 사용한다.
